Make NJIT 2026 24 hour Hardware Hackathon
Project Name: perForm

Our team goal was to create a wearable device utilizing an ESP32 and motion sensors. 
Data from that device as well as a camera feed would be fed to an on device LLM which would provide live feedback based on the user's workout.
The data would be stored on a React Native app that would have past history that the user can use to improve their future workouts.

Saahil focused mainly on app building.
Aruntej focused mainly on LLM integration.
Jake and Sarah focused on the hardware end.
